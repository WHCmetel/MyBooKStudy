AJAX

一、AJAX简介

AJAX全称Asynchronous Javascript And XML，也就是异步的js和XML。

通过AJAX可以在浏览器中向服务器发送异步请求，其最大优势就是无刷新获取数据。AJAX不是新的编程语言，而是一种将现有标准组合在一起的新的数据请求方式。

XML是可扩展标记语言，主要用来传输和存储数据。它和HTML类似，不同的是HTML都是预定义标签，而XML中没有预定义标签，全是自定义标签，用来表示一些数据。例如：有一个学生数据 name='张三'；age=18;gender='男'；

//XML数据展示
<student>
    <name>张三</name>
    <age>18</age>
    <gender>男</gender>
</student>

之前AJAX请求数据都是使用XML格式的数据，但现在已经被JSON格式数据取代,它比XML更简洁，且更容易转化为js对象。

xxxxxxxxxx
//json数据展示
{"name":'张三',"age":18,"gender":'男'}

AJAX的优点：可以无需刷新页面就与服务器端进行通信，允许你根据用户事件来更新页面部分的内容。

AJAX的缺点：没有浏览历史，不能回退，存在跨域问题，SEO不友好。

HTTP协议又叫超文本协议，协议详细规定了浏览器和万维网服务器间互相通信的规则。大部分网页数据交互都是使用HTTP协议。

HTTP协议的内容主要分为：

  • 请求报文(http协议请求的内容)，其结构如下

    xxxxxxxxxx
    请求行  GET /s?ie=wuss HTTP/1.1
    请求头  Host: www.aaa.cn
           Cookie: name=guigu
           Content-type: application/x-www-form-urlencode
           User-Agent: chrome 83
    空行
    请求体   username=admin&password=admin

  • 响应报文(http协议响应的内容),其结构如下

    xxxxxxxxxx
    响应行  HTTP/1.1  200 ok
    响应头  Content-Type: text/html;charset=utf-8
           Content-length: 2048
           Content-encoding: gzip
    空行
    响应体   <html>
                <head></head>
                <body>
                    <h1>扎根是</h1>
                </body>
             </html>

在浏览器的F12控制台中，在网络栏中直接选择具体请求就可查看其请求报文和响应报文。

2.2 ajax请求基础

js中实现AJAX最简单的ajax请求操作步骤：

  1. 创建XMLHttpRequest对象xhr;

  2. 初始化，设置请求的方法与url;

  3. 发送请求;

  4. 事件绑定onreadystatechange，处理响应结果。

编写一个测试网页代码test.html：内容就是按钮点击就创建一个ajax的GET请求。

xxxxxxxxxx
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>AJAX 请求</title>
    <style>
      #result {
        width: 200px;
        height: 100px;
        border: solid 1px pink;
      }
    </style>
  </head>
  <body>
    <button>点击发送请求</button>
    <div id="result"></div>
    <script>
      const btn = document.querySelector("button");
      const div = document.getElementById("result");
      //绑定按钮点击事件
      btn.onclick = function () {
        //最基本的ajax请求创建步骤
        //1. 创建对象 xhr是XMLHttpRequest单词首字母的简写，表示ajax类型的请求
        const xhr = new XMLHttpRequest();


        //2.初始化，设置请求的方法与url
        //无参数的GET请求
        // xhr.open("GET", "http://127.0.0.1:8000/server");
        //有参数的GET请求
        xhr.open("GET", "http://127.0.0.1:8000/server?a=100&b=200&c=300");


        //3.发送请求
        xhr.send();
        //4.事件绑定 处理服务端返回的结果
        //on是当什么的时候触发事件
        //readystate 是xhr对象中属性，表示对象状态有五个值
        /* 0 表示未初始化，最开始值
            1 表示open方法执行完毕
            2 表示send方法执行完毕
            3 表示服务端返回了部分结果
            4 表示服务端返回了全部的结果
        */
        //change表示改变，说明该函数在一次请求中会触发4次
        xhr.onreadystatechange = function () {
          //判断服务端返回了所有的结果
          if (xhr.readyState === 4) {
            //判断响应状态码 200，404 303 状态200到300间都是成功的
            if (xhr.status >= 200 && xhr.status < 300) {
              //处理成功结果 响应头 行 体
              console.log(xhr.status); //状态码
              console.log(xhr.statusText); //状态字符串
              console.log(xhr.getAllResponseHeaders); //所有响应头
              console.log(xhr.response); //响应体
              div.innerHTML = xhr.response;
            } else {
            }
          }
        };
      };
    </script>
  </body>
</html>

创建POST请求

xxxxxxxxxx
//1. 创建对象
const xhr = new XMLHttpRequest();


//2.初始化，设置请求的方法与url POST请求
xhr.open("POST", "http://127.0.0.1:8000/server");


//设置请求头,要设置在发送前
xhr.setRequestHeader('Content-Type','application/x-www-form-urlencoded');
//自定义请求头
xhr.setRequestHeader('name','张三');


//3.发送请求
//post无请求体的请求
// xhr.send();
//post带请求体的请求
xhr.send("a=100&b=200&c=300");


xhr.onreadystatechange = function () {
  //判断服务端返回了所有的结果
  if (xhr.readyState === 4) {
    //判断响应状态码 200，404 303 状态200到300间都是成功的
    if (xhr.status >= 200 && xhr.status < 300) {
      console.log(xhr.response); //响应体
    }
  }
};

AJAX解决IE浏览器缓存内容的问题,就是在设置url时添加时间戳

xxxxxxxxxx
//初始化，设置请求的方法与url POST请求 发送内容添加时间戳，不同时间戳代表不同请求
xhr.open("POST", "http://127.0.0.1:8000/ie?t=" + Date.now());

2.4 ajax请求超时与网络异常

AJAX解决请求超时或网络异常的处理，模拟延时响应可以在服务器的响应上添加定时器模拟。模拟网络异常可直接在浏览器网络中设置为离线。

xxxxxxxxxx
//1. 创建对象
const xhr = new XMLHttpRequest();


//超时设置 2s就超时取消请求
xhr.timeout = 2000;


//超时回调
xhr.ontimeout = function () {
  alert("网络超时，请稍后重试");
};


//网络异常回调
xhr.onerror = function () {
  alert("网络异常，请稍后重试");
};
//2.初始化，设置请求的方法与url POST请求 发送内容添加时间戳
xhr.open("POST", "http://127.0.0.1:8000/server2");


//设置请求头
xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
xhr.setRequestHeader("name", "aaa");

xhr.send("a=100&b=200&c=300");

取消请求使用abort函数就可

xxxxxxxxxx

      //绑定按钮点击事件

        //取消请求

      };
    </script>
  </body>
</html>

取消请求的应用，可以结合防抖写法，编写代码解决ajax短时间多次重复请求的问题。

xxxxxxxxxx
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>AJAX 请求</title>
  </head>
  <body>
    <button>点击发送请求</button>
    <script>
      const btn = document.querySelector("button");
      let xhr = null;
      //标识变量 标识是否正在发送Ajax请求
      let isSending = false;
      //绑定按钮点击事件
      btn.onclick = function () {
        //核心：判断标识,如果相同请求有就取消
        if (isSending) xhr.abort();
        xhr = new XMLHttpRequest();
        //修改标识
        isSending = true;
        xhr.open("GET", "http://127.0.0.1:8000/server2?a=100&b=200&c=300");
        //3.发送请求
        xhr.send();
        xhr.onreadystatechange = function () {
          if (xhr.readyState === 4) {
            //执行完成就修改标识
            isSending = false;
          }
        };
        console.log(xhr.response);
      };


      //绑定按钮点击事件
      btns[1].onclick = function () {
        //取消请求
        xhr.abort();
      };
    </script>
  </body>
</html>

三、JQuery中的AJAX

jquery中编写ajax请求很简单，只需要调用对应的请求函数，传递对应参数即可。

jquery中的ajax的get请求，使用$.get()。

jquery中的ajax的post请求，使用$.post()。

xxxxxxxxxx
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Jquery发送ajax请求</title>
    <!-- 引入bootstrap资源-->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet"/>
    <!-- 引入jquery资源 crossorigin="anonymous"设置就是向该域名发送请求时，将不会携带当前域名下的cookie -->
    <script crossorigin="anonymous" src="https://cdn.bootcdn.net/ajax/libs/jquery/3.5.1/jquery.min.js"></script>
  </head>
  <body>
    <div class="container">
      <h2 class="page-header">Jquery发送ajax请求</h2>
      <button class="btn btn-primary">GET</button>
      <button class="btn btn-danger">POST</button>
      <button class="btn btn-info">通用型方法ajax</button>
    </div>
    <script>
      //按钮1
      $("button")
        .eq(0)
        .click(function () {   
          //jquery编写ajax get请求
          //参数1 请求url地址
          //参数2 请求参数，是个对象
          //参数3 响应函数
          //参数4 响应体类型设置 一般设为json
          $.get( "http://127.0.0.1:8000/jquery-server",{ a: 100, b: "aa" },function (data) {
              console.log(data); //结果为字符串 {"name":"张三"}
            }
            }
          );
        });
      //按钮2
      $("button")
        .eq(1)
        .click(function () {
          //jquery编写ajax post请求
          //参数1 请求url地址
          //参数2 请求参数，是个对象 post参数将不会拼接在url中
          //参数3 响应函数
          //参数4 响应体类型设置 一般设为json
          $.post(
            "http://127.0.0.1:8000/jquery-server",
            { a: 100, b: "aa" },
            function (data) {
              console.log(data); //结果为对象 {"name":"张三"}
            },
            "json"
          );
        });
    </script>
  </body>
</html>

除了上边两种写法，jquery中还有一种通用配置写法，可以发送任何类型的ajax请求。使用$.ajax()，参数是一个配置对象。

通用写法虽然比get,post复杂一些，但可以根据需求自己配置更加灵活。

个性化需要可查看jquery文档:https://www.apiref.com/jquery-zh/index.html

四、axios中的AJAX

六、同源策略与跨域

6.1 同源

同源策略(Same-Origin Policy)最早由Netscape公司提出的，是浏览器的一种安全策略。

同源是指协议、域名、端口号必须完全相同。违背同源策略就是跨域。ajax请求是默认遵循同源策略的。

编写一个响应页面的服务和get请求数据的服务：

xxxxxxxxxx
const express = require("express");


const app = express();


//响应页面的服务
app.get("/home", (request, response) => {
  //响应一个页面
  response.sendFile(__dirname + "/index.html");
});


//请求数据的服务
app.get("/data", (request, response) => {
  //响应一个数据
  response.send('用户数据');
});


//监听服务
app.listen(8000, () => {
  console.log("服务器启动，8000端口监听中");
});

响应页面index.html的内容，直接可以使用ajax请求数据，因为响应页面和请求数据的服务器同源。

响应页面的请求路径是http://127.0.0.1:8000/home，数据请求路径是http://127.0.0.1:8000/data,都是http://127.0.0.1:8000/，因此是同源的。

解决跨域请求的有两种方式：JSONP和CORS。

6.2 JSONP

JSONP(JSON with Padding)是一个非官方的跨域解决方案，纯粹程序员自己开发出来的，只能解决get请求跨域。

JSONP原理是利用网页中有一些标签天生具有的跨域能力，例如：img、link、iframe、script等。

JSONP就是利用script标签的跨域能力来发送请求，获取返回一段包含函数调用js代码，从而获取到数据。

注意: js标签中请求获取的内容只能是js代码，字符串或者其他数据会报错。

案例：模拟script跨域请求

编写一个get服务用于获取get请求，请求路径是http://127.0.0.1:8000/jsonp-server

xxxxxxxxxx
const express = require("express");


const app = express();


//jsonp服务

  const data = {
    name: "json名称测试"
  };
  //将数据转化为json字符串
  let str = JSON.stringify(data);
  //end返回结果，没有多余请求头,注意返回结果是一段js代码，该代码是函数调用
  response.end(`handle(${str})`);
});


//监听服务
app.listen(8000, () => {
  console.log("服务器启动，8000端口监听中");
});

6.3 CORS

CORS(Cross-Origin Resource Sharing),跨域资源共享。CORS是官方的跨域解决方案，它的特点是不需要在客户端做任何特殊的操作，完全在服务器中进行处理。支持get和post请求。

跨域资源共享标准新增了一组HTTP首部字段，允许服务器声明哪些源站通过浏览器有权限访问哪些资源。

CORS通过设置一个响应头来告诉浏览器，该请求允许跨域，浏览器收到该响应以后就会对响应放行。

服务器,核心就是设置响应头setHeader("Access-Control-Allow-Origin", "*")。

xxxxxxxxxx
const express = require("express");


const app = express();


//Cors请求服务
app.all("/cors-server", (request, response) => {
  //设置跨域允许响应头 使用*表示匹配所有，这里只匹配当前跨域的服务
  // response.setHeader("Access-Control-Allow-Origin", "*");
  //匹配特定的服务器
  response.setHeader("Access-Control-Allow-Origin", "http://127.0.0.1:5500");
  //允许headers自定义
  response.setHeader("Access-Control-Allow-Headers", "*");
  //允许方法自定义,指定了访问资源时允许使用的请求方法
  response.setHeader("Access-Control-Allow-Method", "*");
  //让服务器把允许浏览器访问的头部信息放入白名单,这样浏览器就能通过X-My-Custom-Header,X-Another-Custom-Header响应头
  response.setHeader("Access-Control-Expose-Headers", "X-My-Custom-Header,X-Another-Custom-Header");
  //给定了该预检请求可供缓存的时间长短，单位为秒，默认值是5秒。在有效时间内，浏览器无须为同一请求再次发起预检请求
  response.setHeader("Access-Control-Max-Age", 86400);
  //指定了当浏览器的 credentials 设置为 true 时是否允许浏览器读取 response 的内容。
  response.setHeader("Access-Control-Allow-Credentials", true);
  response.send("hello CORS");
});


//监听服务
app.listen(8000, () => {
  console.log("服务器启动，8000端口监听中");
});
